Tasks and repeating habits

  • Due dates, priorities and reminders.
  • Groups, search and bulk edits.
  • Recurring habits with completion history and streaks.
  • Markdown task notes and a daily journal.

Paste lists with text import.

Run locally

With Python 3.13 or newer and Tkinter:

python -m tasklistprogram

No extra Python packages are needed. Tasks are saved locally in SQLite.
